## Niche A — "Grand Manors & Lost Estates"

Big old houses. Rich old families. What happened to them.

- Example: *"The Mansion That Bankrupted a Family"*, *"America's Forgotten Millionaire Row"*
- **Feeling:** money gone, beauty rotting, family shame.
- **Why the money is good:** the topic sits next to real estate + finance + insurance ads. Those advertisers pay the most. Best chance of high RPM.
- **Pictures:** easy and beautiful with AI. Grand rooms, dust, empty ballrooms.
- **Risk:** a few other channels do this. But most of them shout. We whisper.

## Niche B — "Old Ways of Living"

Amish life. Farm life. How things were done before machines.

- Example: *"How the Amish Keep Food Cold Without Electricity"*, *"The Winter Chores That Kept a Family Alive"*
- **Feeling:** warm, cozy, "life was simpler and better".
- **Why it works:** perfect lean-back TV watching. Very calm. Old viewers love it. Very evergreen.
- **Risk:** ads are cheaper here (no finance/real-estate money nearby). RPM will likely be lower than A.
- **Careful:** do not fake facts about real Amish communities, and no real photos of real people. AI images only, and say what is a re-creation.

## My guess before the test

**Niche A makes more money per view. Niche B gets more views.**
The test tells us which one wins overall. Do not skip the test.

## How the test works

1. Make **3 videos for Niche A**, then **3 videos for Niche B**. Same channel is fine at the start.
2. Same everything else: 12 minutes, calm voice, anti-design thumbnail, same upload times.
3. Wait **30 days after the last video**.
4. Fill in the table.

| Video | Niche | Views (30d) | CTR % | Avg view duration | RPM $ |
|---|---|---|---|---|---|
| A1 | A |  |  |  |  |
| A2 | A |  |  |  |  |
| A3 | A |  |  |  |  |
| B1 | B |  |  |  |  |
| B2 | B |  |  |  |  |
| B3 | B |  |  |  |  |

**Winner = the niche with the higher `views × RPM` total.** That is real money, not feelings.

Note: RPM only shows up after the channel is monetized (1000 subs + 4000 watch hours). Before that, judge on **views + average view duration** only, and check RPM later.
